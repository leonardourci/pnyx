# Wakes that need a closer look

- A quiet worker or a waiting request is never nothing: answer the request or nudge the worker yourself.
- `not confirmed` means a reply never showed up in the worker's transcript: resend it, relaunch the worker or tell the owner.
- A routine helper hand-back or escalation: check the task's current state first, since an earlier action may have completed, and do not repeat an automated result.
- An external blocker flag quotes a worker's report of a full suite, a cancelled run or an out-of-date base: verify that evidence before putting the decision to the owner.
