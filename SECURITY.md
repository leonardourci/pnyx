# Security policy

Supported version: the latest commit on `main` (Pnyx is pre-v1).

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/leonardourci/pnyx/security/advisories/new).
Include affected versions, reproduction steps, impact and a minimal example with private data removed.
Keep security reports out of public issues and pull requests while a fix is being coordinated.
